# СтройФорма — магазин строительных материалов

**Контрольная работа №1:** HTML и CSS: разработка многостраничного сайта.

Учебный многостраничный каталог строительных материалов с авторским визуальным оформлением в природных зелёных оттенках. **Это демонстрационный проект, а не действующий магазин:** цены, адрес и контакты вымышлены; формы не отправляют данные на сервер.

## Страницы

- `index.html` — главная: hero, преимущества, популярные товары, призыв к действию.
- `catalog.html` — каталог из 8 товаров, статические категории и якорные ссылки.
- `product.html` — детальная карточка цемента М500, таблица характеристик.
- `order.html` — форма заявки с HTML-валидацией.
- `contacts.html` — контакты, FAQ и переход к форме.
- `success.html` — дополнительная демонстрационная страница после заполнения формы.

## Технологии

HTML5, CSS3, CSS Grid, Flexbox, CSS custom properties, БЭМ. Без CSS-фреймворков и без JavaScript-интерактивности. CSS-модальное окно использует `:target`.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер в папке проекта: `python -m http.server 8000`, затем откройте `http://localhost:8000/`.

## Самостоятельные доработки

1. Оригинальная дизайн-система: собственная палитра, типографика, архитектурный hero, декоративные композиции.
2. Восемь карточек товаров и собственные SVG-иллюстрации, работающие без внешнего хостинга.
3. Дополнительная страница `success.html` с честным пояснением о демонстрационной форме.
4. Хлебные крошки, FAQ, категории каталога, якорные ссылки, sticky-меню и боковая панель.
5. CSS-модальное окно без JavaScript, фиксированная кнопка «Наверх».
6. Состояния hover/focus-visible, подписи полей, семантика, адаптация под узкие экраны.

**Ограничения:** категории не выполняют динамическую фильтрацию; карточки каталога ведут на одну демонстрационную страницу товара; заявка не сохраняется и не отправляется. Полноценную логику можно добавить в последующих контрольных работах.
